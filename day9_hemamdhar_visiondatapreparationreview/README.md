# Day 9 - Vision Data Preparation Review

This folder is the three-slide progress pack and frozen data-preparation plan for the underwater visual surveillance project.

## Deliverables

- `three_slide_progress_pack.md` - presentation-ready three-slide review.
- `approved_data_plan.md` - versioned data-preparation plan, decision gates, and mentor sign-off block.

## Evidence status

Day 8 documents that the raw archive is not yet populated and the inspection JSON files contain no measured records. Therefore the pack separates verified status from provisional risks and provides sample-review slots that must be filled from the archive. It does not present invented counts, images, defect rates, or approval signatures.

## Review sequence

1. Populate and checksum the Day 7 raw archive.
2. Run the Day 7 inspection notebook and complete the Day 8 results register.
3. Fill the difficult/inconsistent sample table with real image paths, thumbnails, and reviewer decisions.
4. Confirm the frozen manifest, class maps, and group-aware splits against `approved_data_plan.md`.
5. Obtain mentor approval before baseline training or irreversible preprocessing.
